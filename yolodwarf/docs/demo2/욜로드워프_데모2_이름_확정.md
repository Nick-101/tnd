# 욜로드워프 데모 2.0 이름 (확정)

> 2026-11-24. **이 문서가 데모 2.0 이름의 기준이다.** 이름을 붙일 190개(건물 95채, 특성 5개, 드워프 90마리)를 한곳에 모았다.
> 원칙과 방법은 `이름짓기_2~4단계_유형_원칙_방법.md`에, 이름마다의 까닭과 버린 후보는 적용 문서 다섯(1차부터 5차)과 `yolodwarf2_names.json`에 있다. 여기에는 결과만 적는다.
> 문구는 `욜로드워프_데모2_텍스트_v3.md`의 것이다. 수치는 모두 임시다. 영어 이름은 초안이다.

## 2. 이름을 읽는 법

이름은 정보다(사용자가 정한 것). 그래서 이름의 꼴에 읽는 법이 있다.

| 꼴 | 뜻 | 예 |
|---|---|---|
| 매장의 꼬리말 **바, 카페, 가게, 식당** | 술집, 카페, 쇼핑, 식당의 매장이다 | 재즈 바, 북카페, 와인 가게, 프로틴 식당 |
| 업종이 둘인 매장의 머리말 | 나머지 한 업종을 말한다 | 스포츠 바는 운동과 술집, 보드게임 카페는 오락과 카페 |
| 지원 건물의 명사 | 돕는 업종을 말한다. 그 업종에 무엇을 대는 곳인가로 지었다 | 농장은 식당, 로스터리는 카페, 고블린 공장은 오락, 공방은 쇼핑, 선수촌은 운동, 양조장은 술집, 기획사는 공연, 의자 공장은 휴식. 광고탑은 업종을 가리지 않는다 |
| 꾸미는 말이 없는 지원 건물 | 가까운 곳에 닿는다(업종 가족과 광고탑) | 농장, 광고탑 |
| **대형** | 온 마을에 닿는다(모든 곳) | 대형 농장, 대형 양조장, 대형 광고탑 |
| **왕실** | 가장 비싼 한 곳만 상대한다 | 왕실 농장, 왕실 광고탑 |
| **특훈, 밤샘, 앙코르** | 가까운 곳을 한 번 더 이용하게 한다 | 특훈 선수촌, 밤샘 양조장, 앙코르 기획사 |
| **안락** | 가까운 곳에서 더 잘 쉬게 한다 | 안락의자 공장 |
| **길드** | 어떤 매장들의 모임이다 | 장인 길드(업종이 하나인 매장), 퓨전 길드(업종이 둘인 매장), 상인 길드(모든 매장) |
| **사무소** | ★(업그레이드)을 읽는다 | 건축 사무소, 인테리어 사무소 |
| 드워프 | 뜻이 없다. 서로 구별만 한다. 소리대로 적는다 | 발둔 Baldun, 볼가 Bolga |

알아 둘 것. "대형이면 온 마을"은 언제나 맞지만 "온 마을이면 대형"은 아니다(신문사, 여행사). 왕실도 같다(방송국, 2호점). 꾸미는 말은 바탕 이름의 건물이 따로 있을 때만 붙였다. "대형"은 닿는 범위만 말하고 무엇을 하는지는 문구가 말한다.
