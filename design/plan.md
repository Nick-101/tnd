# 주사위 덱빌딩 — 데모 기획서 (plan)

> 코어 매커니즘 검증용 데모. 원본 기획안(manual.md)의 규격을 따른다.
> 기술: 빌드 도구 없이 브라우저에서 바로 열리는 단일 HTML + ES 모듈. 로직(js/game.js)과 렌더(js/render.js) 완전 분리 — headless 테스트 가능.

## 핵심 규칙 요약

- 주사위 5개, 각 면 1~6 (숫자 변경권으로 최소 1 ~ 최대 9까지 조정 가능).
- 스테이지 8개. 각 스테이지 목표 점수를 **턴 4회** 안에 달성해야 한다.
  - ⚠️ 원본 기획안에 "총 4번의 턴" / "이 5번의 턴" 표기가 충돌 → "재굴림 기회는 턴당 2회" 서술과 일관된 **4턴**으로 확정.
- 턴 시작 시 자동으로 전체 굴림. 턴당 굴림 3회(= 재굴림 2회). 잠긴 주사위는 굴림 제외, 잠금 토글 무제한.
- 턴 종료 시: 각 주사위의 스킬이 먼저 발동 → 최종 값의 합이 점수에 가산. 잠금 전체 해제.
- 목표 달성 즉시 스테이지 클리어 → 보상(무작위 스킬 3개 + 숫자 변경권 2개) → 정비 화면 → 다음 스테이지.
- 4턴 소진 후 목표 미달 → 패배.
- 8스테이지 클리어 → 승리.

### 세부 결정 사항 (원본에 없는 부분을 합리적으로 채움)

| 항목 | 결정 |
|---|---|
| 숫자 변경권 범위 | 면의 눈은 1 미만/9 초과 불가. 한계값에서 해당 방향 버튼 비활성. |
| 스킬 장착 중복 | 이미 스킬이 있는 면에 장착 시 기존 스킬은 인벤토리로 반환(교체). |
| 숫자 변경으로 조건 위반 | 숫자 변경 후 그 면의 스킬 조건이 깨지면 스킬은 인벤토리로 자동 반환(로그 표시). |
| 보상 스킬 추첨 | 전체 풀에서 무작위 3개, 중복 허용. |
| "4 이상/3 이하" 조건 | 눈이 9까지 커질 수 있으므로 "4~6"형 조건은 "4 이상", "1~3"형은 "3 이하"로 정의. |
| 스킬 발동 순서 | 1번 주사위 → 5번 주사위 순. 개별 효과 먼저 전부 계산 후, 총점 계열 효과를 같은 순서로 적용. |
| 소수점 | 모든 계산은 정수. 나눗셈은 내림. |

## 1. 주사위 스킬 (35종)

조건 표기 — 모두: 아무 눈에나 장착 / 3 이하 / 4 이상 / 짝수 / 홀수 / n만: 눈이 n인 면에만 장착.
"눈"은 스킬이 붙은 면이 굴림에서 나온 값. 별도 표기 없으면 자기 주사위 점수에 대한 효과.

| 이름 | 조건 | 효과 |
|---|---|---|
| 잔돈 줍기 | 모두 | 눈 +8 |
| 묵직한 한 방 | 4 이상 | 눈 +15 |
| 밑바닥 근성 | 3 이하 | 눈 +18 |
| 짝수 예찬 | 짝수 | 눈 ×4 |
| 홀수 반란 | 홀수 | 눈 ×4 |
| 삼위일체 | 3만 | 눈 ×6 |
| 로또 | 6만 | 눈 ×6 |
| 개미 군단 | 1만 | 눈 +35 |
| 쌍둥이 자석 | 모두 | 나와 같은 눈인 다른 주사위 하나당 +15 |
| 짝수 동맹 | 짝수 | 짝수 눈 주사위 하나당 +12 (자신 포함) |
| 홀수 동맹 | 홀수 | 홀수 눈 주사위 하나당 +12 (자신 포함) |
| 어부지리 | 모두 | 다른 주사위 중 가장 높은 눈 ×2 만큼 + |

| 육형제 | 모두 | 눈이 정확히 6인 주사위 하나당 +18 (자신 포함) |

## 2. 스테이지

| 스테이지 번호 | 목표 점수 |
|---|---|
| 1 | 70 |
| 2 | 100 |
| 3 | 200 |
| 4 | 240 |
| 5 | 310 |
| 6 | 400 |
| 7 | 500 |
| 8 | 620 |

1~3스테이지는 원안 예시(70/100/200) 그대로. 4~8은 headless 봇 시뮬레이션(40판 성장 곡선 실측 + 100판 승률 측정)으로 보정한 값 — 무스킬 4턴 기대치가 ~86점이라 1스테이지는 맨손 통과 가능, 3스테이지(100→200 점프)가 최대 관문, 이후는 스킬 투자 효율이 좋은 플레이어만 완주하는 곡선(기여도-그리디 봇 승률 ~20%).

## 3. 조작 체계

마우스만 사용한다. 키보드 입력은 사용하지 않는다.

- 주사위 클릭: 잠금 토글
- 버튼 클릭: 굴림 / 턴 종료 / 스킬 장착 / +1 / −1 / 다음 스테이지 / 재시작 / 스킬 도감 열기·닫기
- 마우스 올리기(호버): 스킬이 장착된 주사위·전개도 면·인벤토리 카드에서 상세 설명 툴팁 표시
- 로그창: 마우스 스크롤(드래그)로 이전 내역 열람

## 4. 화면 구성(UI)

분위기: 발라트로(Balatro) 풍 — 짙은 펠트 그린 배경, 흰색 라운드 카드, 붉은 포인트 버튼, 굵은 타이포. 애니메이션 없음(경량화), 진행은 전부 로그로 표기.

**스테이지 화면**
- 스테이지 정보 사이드바(좌측): 스테이지 번호, 목표 점수, 현재 점수, 남은 턴 수, 남은 굴림 기회.
- 주사위 판(중앙): 주사위 5개 나란히. 현재 면에 스킬이 있으면 스킬 이름 배지 표시, 호버 시 상세 설명 툴팁. 클릭으로 잠금 토글(잠김 표시). 하단에 [굴림] [턴 종료] 버튼.
- 로그창(우측 하단): 텍스트 전용, 스크롤로 이전 내역 열람. 스킬 발동 시 "주사위 n · '스킬명' 발동: 눈 → 결과값" 형식 기록. 정비 화면에서도 같은 로그가 이어서 보인다.
- 스킬 도감: 사이드바(스테이지)·우측 패널(정비)의 [스킬 도감] 버튼으로 오버레이 열림. 전체 35종을 개별 스킬/총점 스킬로 나눠 이름·조건·효과·상세 설명 표기.

**정비 화면**
- 주사위 관리 패널: 주사위 5개 표시, 하나 선택 시 전개도(십자형)로 펼침. 각 면 선택 → 스킬 장착 / +1 / −1 가능.
- 인벤토리: 보유 스킬 목록(조건·효과 표기, 선택한 면에 장착 불가하면 비활성, 호버 시 상세 설명 툴팁), 숫자 변경권 개수.
- 로그창: 좌측 하단에 스테이지 플레이 로그가 이어서 표시.
- [다음 스테이지] 버튼.

**종료 화면**: 승리/패배 문구 + [처음부터] 버튼.

## 완료 기준 목록

- [ ] 턴이 시작되었을 때 주사위가 모두 굴려진다.
- [ ] 주사위의 잠금 상태 토글이 잘 작동한다.
- [ ] 잠긴 주사위는 굴림에서 제외된다.
- [ ] 턴을 종료하면 주사위 눈과 스킬에 맞게 점수를 획득한다.
- [ ] 목표 점수를 달성하면 스테이지가 클리어된다.
- [ ] 스테이지 클리어 이후 보상이 주어진다.
- [ ] 스테이지 클리어 이후 정비 화면으로 전환된다.
- [ ] 정비 화면에서 주사위 면에 스킬을 장착하거나 숫자 변경권으로 숫자를 변경시킬 수 있다.
- [ ] 다음 스테이지로 진행이 가능하다.
- [ ] 턴을 모두 소모했을 때 목표 점수를 달성하지 못하면 게임에서 패배한다.
- [ ] 브라우저 콘솔에 에러가 0건이다
