# TnD 주사위 덱빌딩 — 데모 기획서 (plan, v2)

> 코어 매커니즘 검증용 데모. 원본 기획안 v2(TnD 주사위 덱빌딩 기획안 데모 v2)의 규격을 따른다.
> 기술: 빌드 도구 없이 브라우저에서 바로 열리는 단일 HTML + ES 모듈. 로직(js/game.js)과 렌더(js/render.js) 완전 분리, 점수 계산은 순수 함수 `calcScore` — 프리뷰와 턴 종료가 같은 함수를 호출한다.

## 핵심 규칙 요약 (v2)

- **면 슬롯(F1~F6)과 눈(숫자)은 분리.** 맞은편 관계 F1↔F6 · F2↔F5 · F3↔F4 고정.
- **주사위 1개 + 스타터 스킬 3개**(F6 정타 / F1 잔향 / F2 여운)로 시작, 스테이지 1~4 클리어마다 +1개(고정 지급), 최대 5개.
- 스테이지 8개 × 4턴, 턴당 굴림 3회(재굴림 2회). 잠금 토글 무제한, 턴 종료 시 전체 해제.
- **점수 = 단일 누산기 순차 연산**: S ← 활성 눈 합 → 주사위 순서대로, 각 주사위 안에서 활성 → 맞은편 → 측면(F1→F6) 순으로 스킬이 S에 `+n`/`×n`. 중간은 실수(표시 소수 1자리), **최종 점수만 내림**.
- 면 상태 4계층: **활성**(윗면, 1/6) / **맞은편**(바닥면, 1/6) / **측면**(4/6) / **잠재**(활성이 아님, 5/6). 스킬은 자기 계층 상태에서만 발동.
- 보상: **스킬 드래프트**(1~4스테이지 4택2, 5~7스테이지 5택3) + 숫자 변경권 2개(눈 1~6 범위 ±1). 스테이지 8 클리어 = 게임 승리.
- **주사위 순서 변경은 정비 화면에서만** (◀▶ 버튼). 스테이지 진입 시 고정.
- **실시간 예상 점수 프리뷰** 상시 표시. 로그는 한 줄씩(약 95ms) 순차 출력, 덧셈=청색 / 곱셈=적색 / 클리어=금색.

### 기획안 v2의 모호점 해석 (구현 확정 사항)

| 항목 | 기획안 표기 | 확정 |
|---|---|---|
| 스킬 총수 | 본문 "총 44종", 표 합계 48종 | **표 기준 48종 구현** |
| 드래프트 규모 | 본문 "6~8은 5택3", 표는 5스테이지도 5택3 | **표 기준: 1~4는 4택2, 5~7은 5택3, 8은 클리어** |
| 2.4 계산 예시 | 예시 로그가 명시된 면 순회 규칙(활성→맞은편→측면)과 어긋남 (3번 주사위에서 활성 '후위'가 맞은편 '심층' 뒤에 적용됨) | **명시된 알고리즘을 규범으로** — 활성 먼저 |
| '여유'의 남은 턴 | 미정의 | **이번 턴을 제외한 잔여 턴** (턴 1에서 3) |
| '반복'의 발동 횟수 | 미정의 | **이번 발동 포함** (1, 2, 3…), 스테이지 시작 시 초기화 |
| '각인'의 증가 대상 | 미정의 | 장착/인벤토리 불문 **모든 각인 인스턴스**가 클리어 시 +5 |
| 성장형 누적의 귀속 | 미정의 | **스킬 인스턴스별** 보유 (같은 스킬 2장이면 각자 성장) |
| 눈 변경으로 장착 조건 파괴 | 미정의 | 해당 스킬은 **인벤토리로 자동 반환** (로그 표기) |
| 드래프트 중복 | 미정의 | 한 제시 안에서는 중복 없음, 회차 간 중복 허용 |
| 잠금 로그 | "잠금 변경" 기록 요구 | 토글 단위로 "주사위 n 잠금/해제" |

## 1. 주사위 스킬 (48종)

조건 표기: `발동 계층 · 장착 가능 눈`. 등급 드롭률 일반 60% / 고급 30% / 희귀 10%.
전체 표는 기획안 v2 3장의 값을 그대로 구현했다. **예외(밸런스 조정)** 는 아래 3건뿐:

| 이름 | 기획안 | 조정 | 근거 |
|---|---|---|---|
| 미열 | 잠재 ×1.2 | **×1.25** | 기획안 8절 튜닝 1순위 "잠재형 곱셈 배수" — 본 구현 실측에서 후반 성장 부족. 상한 ×1.3 준수 |
| 실선 | 잠재 ×1.25 | **×1.3** | 〃 |
| 저음 | 잠재 ×1.25 | **×1.3** | 〃 |

전체 목록·수치·상세 설명은 `js/config.js`(SKILLS, SKILL_DETAILS)와 게임 내 **스킬 도감**에서 확인 (이름 | 등급 | 조건 | 효과 순으로 9개 분류: 활성 덧셈 8 / 활성 곱셈 5 / 맞은편 6 / 측면 4 / 잠재 8 / 집합 4 / 자원 4 / 순서·누산기 5 / 성장 4).

## 2. 스테이지

| 스테이지 | 목표 점수 | 주사위 수 | 클리어 보상 |
|---|---|---|---|
| 1 | 30 | 1 | 4택2 · 변경권 2 · 주사위 +1 |
| 2 | 65 | 2 | 4택2 · 변경권 2 · 주사위 +1 |
| 3 | 110 | 3 | 4택2 · 변경권 2 · 주사위 +1 |
| 4 | 160 | 4 | 4택2 · 변경권 2 · 주사위 +1 |
| 5 | 240 | 5 | 5택3 · 변경권 2 |
| 6 | 330 | 5 | 5택3 · 변경권 2 |
| 7 | 460 | 5 | 5택3 · 변경권 2 |
| 8 | 620 | 5 | **게임 클리어** |

기획안 표(30/65/125/230/380/640/1050/1650)에서 3~8스테이지를 하향 조정했다. 근거는 기획안 8절의 자체 규칙 — "목표를 재조정할 때는 목표/4턴 능력치 중앙값 비율을 0.7 부근으로 유지":

- 본 구현으로 그리디 봇(기획안 8절의 플레이어 모델 재현: 평균 기대값 기반 재굴림, 곱셈 우선 드래프트·후방 배치)의 4턴 총점 중앙값을 부활 모드 40판으로 실측 → `40 / 91 / 152 / 206 / 296 / 386 / 510 / 645`.
- 기획안 시뮬레이션 중앙값(45→2381)과 초반 3스테이지는 일치하지만 후반은 괴리 — 원인은 드래프트 운(곱셈 스킬은 고급·희귀 풀에만 존재)에 따른 편차로, 봇 최대값(3096)은 기획안 수준에 도달함.
- 조정 후 봇 완주율 41%/80판 (기획안의 약한 모델 예상 37%와 근접, 실제 플레이어는 더 높음). 탈락 분포가 특정 스테이지에 몰리지 않음.

## 3. 조작 체계

**마우스 전용.** 키보드 입력 없음.

스테이지: 주사위 좌클릭=잠금 토글 / 주사위 호버=6면 구성 툴팁(슬롯·눈·상태·스킬) / 굴림(잔여 표기)·턴 종료 버튼 / 로그 스크롤.
드래프트: 카드 좌클릭=선택 토글(정원 초과 불가), 정확히 채우면 확정 버튼 활성.
정비: 카드 좌클릭=전개도 / `◀ ▶`=순서 변경(드래그 대신 버튼 우선 — 기획안 구현 노트) / 면 좌클릭=선택 / 스킬이 있는 면 우클릭=회수 / 인벤토리 스킬 좌클릭=선택한 면에 장착 / 눈 ±1 버튼 / 다음 스테이지.
공통: 스킬 카드·면·도감 호버 시 상세 설명 툴팁, [📖 스킬 도감] 버튼.

## 4. 화면 구성 (UI)

발라트로풍 펠트 그린 + 흰 카드. 덧셈=청 / 곱셈=적 / 목표 달성=금. 숫자가 주인공. 애니메이션 없음 — 로그 한 줄씩 순차 출력(95ms)이 연출을 대체.

**스테이지 화면** — 좌측 사이드바(스테이지, 목표, 현재 점수, **진행률 바**, 남은 턴, 남은 재굴림, 보유 스킬 수, 변경권 수, 도감 버튼) / 중앙 주사위 판(계산 순서대로 ①②③…, 활성 면 슬롯 표기, 잠금 배지) + **예상 점수 패널** + 굴림·턴 종료 / 우측 하단 로그창.

**드래프트 화면** — 클리어 직후. 스킬 카드(이름·등급·계층·조건·효과·예상 발동률) 4~5장, N장 선택 시 확정. 하단에 로그 이어짐.

**정비 화면** — 주사위 카드(순번, `◀▶`, 구성 요약 뱃지 `덧셈 n · 곱셈 n · 빈면 n`) → 클릭 시 십자 전개도(슬롯명 F1~F6 · 눈 · 스킬 · 계층 색). 선택 면의 **맞은편 슬롯이 금색 점선 + '맞은편' 라벨**로 표시. 면 선택 후 눈 ±1 / 스킬 장착 / 우클릭 회수. 우측 인벤토리(계층·등급 칩, 성장형은 현재 값 표기, 장착 불가 시 비활성) + 다음 스테이지. 좌측 하단에 로그 이어짐.

**종료 화면** — 승리/패배 + 처음부터.

**스킬 도감** — 양쪽 화면에서 버튼으로 오버레이. 48종을 9개 분류로, 이름·계층·등급·조건·효과·상세 설명(발동 시점, 계산 방식, 예시).

### 추가 완료 기준 (v2 신규 시스템)

- [x] 점수가 주사위 순서대로 계산되며, 로그의 누산값이 최종 점수와 일치한다.

- [x] 스테이지 1~4 클리어 시 주사위가 1개씩 추가되어 최대 5개가 된다.
- [x] 장착 조건을 만족하지 않는 슬롯에는 스킬을 장착할 수 없다.
- [x] 숫자 변경권으로 눈을 1 미만 또는 6 초과로 만들 수 없다.
- [x] 전개도에서 선택한 면의 맞은편 슬롯이 시각적으로 표시된다.
- [x] 로그가 한 줄씩 순차적으로 추가되며, 곱셈 줄이 덧셈 줄과 구분되어 표시된다.
- [x] 성장형 스킬의 누적 값이 스테이지를 넘어 유지된다.
- [x] 8스테이지를 클리어하면 게임 승리 화면이 표시된다.
