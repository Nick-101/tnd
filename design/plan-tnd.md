# TnD 결합 데모 — 기획서 (plan, 결합 v2.1)

> 주사위 덱빌딩 엔진(4계층 면 스킬 · 단일 누산기 · 올림) 위에 모노폴리 디펜스를 결합한 단일 고행 데모. 원본 기획안(TnD 결합 데모 기획안 v2.1)의 규격을 따른다.
> 코드: `js/tnd-config.js`(각인 18 · 면 스킬 52 · 기물 20 · 몬스터 데이터) · `js/tnd-game.js`(순수 로직: `calcFaithPoints` / `convert` / `resolveMove` / `resolveEnemyMove`) · `js/tnd-render.js`. 검수: `test/tnd.test.mjs`, `test/tnd-bot.mjs`. 스테이지 데모(design/plan.md)는 그대로 유지.

## 핵심 루프 (구현 범위)

정비(주사위 3개: 각인 1 + 면 스킬 6 · 눈 무제한 · 계산 순서 · 기물덱 5) → 고행 → [플레이어 턴: 굴림(재굴림 2) → 확정·정산 → **주사위 3개를 원하는 순서로 전부 이동**(구간마다 그 주사위의 각인 방식으로 밟음/멈춤 처리 → 강제지불·정화·내멈 효과·건설/파괴) → 건설 단계(**원격 업그레이드**, 이번 턴 멈춘 칸 반값) → 턴 종료(타락 −1)] → [적 턴: 패턴의 다음 행동 1개 실행, 의도는 항상 공개] → 승리(적 신앙 ≤ 0) / 패배(강습·강제지불 불능 → 게임 포기) → 정비 복귀.

### 기획안 v2.1의 모호점 해석 (구현 확정 사항)

| 항목 | 확정 |
|---|---|
| 순례자의 첫 이동 | 시작칸 0에서 출발하는 첫 걸음부터 비행 구간(1~8)을 건너 9번 칸에 착지 (1~8은 절대 밟지 않는다는 §6 우선). 이후 한 바퀴 = 24걸음 |
| 강습 시점 | 시작칸에 닿는 걸음에서 청구. 적 턴을 멈추고 지불/판매/게임 포기 창 → 응답 후 남은 걸음 재개 |
| 공허의 "잠재면" | 윗면이 아닌 면(맞은편·측면·잠재 계층 스킬 모두)의 효과를 2배/제곱 |
| 인내 | 잠근 채 턴 종료 → 다음 턴에도 잠긴 채 유지되며 눈 +1(누적, 최대 6). 굴리면 초기화 |
| 균형 | 턴 시작 굴림에는 적용 안 됨(직전 눈이 없음), 재굴림에만 |
| 헌신 | 활성면에 스킬이 없으면 기본 눈합에 눈×3으로 넣는다 |
| 축복 | 이 구간에서 밟거나 멈춘 내 기물 모두 등급 +1로 취급 (밟음은 멈춤을 포함) |
| 이정표 | 이동당 1회, 밟은 첫 이정표가 그 구간의 거리를 +1 (은밀은 밟지 않으므로 제외). 프리뷰도 같은 함수 |
| 성좌 오라 | 적이 밟는 모든 칸에서 적멈 훅도 발동, 타락 칸이면 카운터 −1 (전 보드) |
| 성배 오라 | 정산 전후 잔량 9 고정 → 모든 신앙치가 1:1 |
| 신전 오라 | 신전 자신을 제외한 내 기물 등급 +2, 턴 시작 신앙 +10×신전 등급 |
| 종탑 후퇴 | 되돌아간 칸은 밟지 않음. 9번 칸 아래(비행 구간)로는 내려가지 않음 |
| 심판소 | 적 현재 신앙의 5G% (대성당 ×2 포함, 최대 100%) 올림 |
| 순례길 연쇄 | 멈춤 효과 즉시 G칸 기본 이동, 도착 칸에서 다시 전체 상호작용 (이정표·연쇄 중첩 가능) |
| 멈춘 칸에서의 업그레이드 | 멈춤 시에는 창을 띄우지 않고, 건설 단계에서 어느 기물이든 클릭해 업그레이드(멈춘 칸은 등급당 비용÷4) |
| 플레이어 시작 신앙 · 기물덱 | 0 · 소모되지 않는 건설 메뉴 (v1과 동일) |
| 정비 초기 상태 | 권장 입문 빌드(6스킬) + 권장 입문 덱(제단·제단·성소·우물·첨탑). 각인은 비워 둔다 |

## 1. 각인 (18종)

주사위당 1개, 같은 각인 중복 불가. 이동형 5(도약=순간이동 · 비약=점프2 · 순례=서행 · 은신=은밀 · 활보=기본+1) / 굴림형 4(재도 · 인내 · 불굴 · 균형) / 정산형 5(공허 · 종장 · 서장 · 짝의 심장 · 헌신) / 보드형 4(축복 · 정화의 발걸음 · 개척 · 징수). 전체 효과·상세는 `ENGRAVINGS`, `ENGRAVING_DETAILS`와 정비 화면 각인 목록(종류 필터·툴팁).

## 2. 면 스킬 (52종)

v1 57종에서 이동 계층 5종 제외. 귀향 = 안전지대(1~8)에서 +12, 각인의 기억 = +5 시작·바퀴당 +3, 집합 참조는 활성 눈 3개 기준. 미열 ×1.25·실선/저음 ×1.3(상한 ×1.3)은 이전 조정값 유지.

## 3. 기물 (20종, 티어 I~V)

| 티어 | 기물 (비용) |
|---|---|
| I | 말뚝 2 · 제단 3 · 우물 3 · 이정표 4 · 묘지 5 |
| II | 성소 10 · 정화소 12 · 종탑 12 · 회당 15 · 봉화 15 · 세리 20 |
| III | 성물함 50 · 첨탑 60 · 순례길 70 · 성문 80 |
| IV | 심판소 350 · 대성당 400 · 성좌 500 |
| V | 신전 2,000 · 성배 3,000 |

훅은 기획안 §13 표 그대로(`PIECES[].desc`). 업그레이드 등급당 비용÷2(멈춘 칸 ÷4), 판매 비용×G÷2, 파괴 최종 비용×1.5, 사악한 기물 비용 2G+G×M, 정화 1→+2씩. 모두 올림.

## 4. 몬스터 — 데이터 정의

`MONSTERS.pilgrim` = { 신앙 250, 기본 이동, 패턴 ①이동6 ②이동5 ③타락1 ④이동7 ⑤이동6 ⑥소환1, 기믹 비행(1~8 → 9), 강습 5·10·20·40·80·160 }. `new TndGame({ monster })`에 다른 정의 객체를 넘기면 코드 수정 없이 동작한다 (행동 종류: move · corrupt · summon · empower · heal · wait). 타락·소환은 방어선(9~31)에만.

## 5. 조작 (마우스 전용)

정비: 각인 목록 클릭 → 각인 슬롯 클릭(우클릭 회수) / 스킬 목록 클릭 → 면 클릭(우클릭 회수) / 눈 ± / ◀▶ / 기물 목록(티어 필터) 클릭 → 덱, 덱 슬롯 우클릭 제거 / 고행 시작.
고행: 주사위 클릭 = 잠금(굴림 단계)·구간 이동(행동 단계) / 주사위 호버 = 현재 위치 기준 경유(연한)·도착(진한) 칸 프리뷰 / 경로 계획 토글 = 남은 주사위 순열의 멈춤 후보 점 표시 / 적 의도 패널 호버 = 경로 강조, 도착 칸 ★ 상시 / 건설 단계에 내 기물 클릭 = 업그레이드 창(등급 선택·총액·반값 뱃지) / 턴 종료 / 대화창(지불·판매·게임 포기 / 정화 / 파괴 / 건설) / 덱 정보.

## 6. 화면

상단바(턴 · 신앙 · 적 이름과 HP 바 · 바퀴와 다음 강습 · 기물/타락 수 · 게이지) / 우측 상단 적 의도 패널(다음 행동 · 경유 범위 · 도착 ★ · 그 다음 행동 · 패턴 진행도) / 마름모 보드(1~8 안전지대 다른 바탕, 티어 로마자, IV·V는 크게, ★ 적색) / 중앙 주사위 판(순번 ①②③ = 계산 순서, 각인 이름과 이동 방식, `구간 k/3`, 사용한 주사위 흐림) / 어두운 순차 로그(결정=금 · 사건=주황 · 행동=흰 · 계산=회/청/적, 효과 없는 경유는 `밟음 칸 a~b (효과 없음)` 한 줄로 접음).

## 7. 밸런스 검증 (본 구현, 봇 20판 × 5빌드, 각인 미장착)

| 빌드 | 면 스킬 | 승률 | 승리 턴 중앙 | 기획안 §18 |
|---|---|---|---|---|
| 입문 | 6 | 0% | — (패배 턴 23) | 0% |
| 입문+ | 7 (+침강) | 0% | — (29) | 0% |
| 준중급 | 8 (+증폭) | 100% | 19 | 99% / 20 |
| 중급 | 9 (+후위) | 100% | 14 | 100% / 16~19 |
| 상급 | 12 (+실선·저음·반향) | 100% | 10 | 100% / 10 |

"증폭 하나가 무릎(신앙치 65)을 넘기는가"가 승패를 가르는 기획안의 구도가 그대로 재현되어, 별도 튜닝 없이 기획안 수치를 채택했다.

- [x] 정비 화면에서 기물을 덱에 포함하거나 뺄 수 있다.
- [x] 정비화면에서 고행을 시작할 수 있다.
- [x] 주사위의 잠금 상태 토글이 잘 작동한다.
- [x] 잠긴 주사위는 굴림에서 제외된다.
- [x] 주사위를 확정하면 주사위 눈과 스킬에 맞게 신앙치를 획득한다.
- [x] 주사위를 하나씩 사용하여 그 만큼 이동한다.
- [x] 적이나 플레이어가 기물을 밟으면 그 효과가 적절하게 발동된다.
- [x] 기물 건설 시, 정화 시, 적 기물 파괴 시, 기물 업그레이드 시 신앙이 정확히 지불된다.
- [x] 타락한 칸을 밟았을 때 정화 상호작용 창이 정상적으로 뜬다.
- [x] 플레이어 기물이 있는 칸을 밟았을 때 업그레이드 창이 정상적으로 뜬다. (v2.1: 건설 단계에서 기물 클릭)
- [x] 타락 카운터가 0이 되면 적 기물이 건설된다. 만약 플레이어 기물이 있다면 파괴되고 건설된다.
- [x] 강제지불 시 기물 판매가 가능하다.
- [x] 고행 클리어 이후 정비 화면으로 전환된다.
- [x] 브라우저 콘솔에 에러가 0건이다.

### 추가 완료 기준 (v2 신규 시스템)

- [x] 주사위마다 각인 1개를 장착·회수할 수 있고, 같은 각인은 중복 장착되지 않는다.
- [x] 행동 단계에서 주사위 3개를 모두 사용해야 턴을 마칠 수 있고, 각 주사위는 눈만큼 반드시 이동한다.
- [x] 주사위를 어떤 순서로 쓰든 최종 도착 칸은 `시작 위치 + 눈 합`이다 (거리 변경 효과 제외).
- [x] 구간마다 멈춤 처리(상호작용·건설·업그레이드)가 일어나고, 다음 주사위는 그 뒤에 선택한다.
- [x] 경로 계획 토글이 남은 주사위의 모든 순열로 도달 가능한 멈춤 칸을 정확히 표시한다.
- [x] 이동형 각인에 따라 경유 칸의 밟음/멈춤 판정이 §5.2 표대로 달라진다 (구간마다 그 주사위의 방식 적용).
- [x] 행동 단계에서 주사위에 마우스를 올리면 경유 칸과 도착 칸이 보드에 미리 표시되고, 실제 이동 결과와 일치한다.
- [x] 강제지불은 멈춤에서만 발생하고, 밟음(경유)에서는 발생하지 않는다 (서행은 경유 칸도 멈춤).
- [x] 은밀 이동은 경유·도착 어디서도 효과를 발동하지 않는다.
- [x] 굴림형·정산형·보드형 각인이 각각 정의대로 작동하며 로그에 남는다.
- [x] 기물의 내밟/내멈/적밟/적멈 네 훅이 올바른 시점에만 발동한다.
- [x] 오라(대성당·성좌·신전·성배)가 범위 내 기물과 규칙에 정확히 적용된다.
- [x] 건설 단계에서 보드 위 어느 내 기물이든 업그레이드할 수 있고, 이번 턴 멈춘 칸의 기물은 반값이다.
- [x] 적 의도 패널이 다음 행동·경유 칸·도착 칸을 표시하고 실제 적 행동과 일치한다.
- [x] 적이 패턴을 순서대로 순환 실행한다.
- [x] 적이 시작칸을 지나면 강습 비용이 바퀴 수에 맞게 청구되고, 9번 칸으로 도약해 1~8을 밟지 않는다.
- [x] 강습 또는 강제지불을 못 하면 게임 포기 버튼이 노출된다.
- [x] 적 신앙이 0 이하가 되면 즉시 승리 처리된다.
- [x] 신앙치→신앙 변환이 §4 변환표와 일치한다.
- [x] 몬스터 정의를 데이터로 교체하면 다른 패턴·기믹이 코드 수정 없이 동작한다.
