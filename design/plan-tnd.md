## 핵심 루프 (구현 범위)

정비(주사위 3개: 각인 1 + 면 스킬 6 · 눈 무제한 · 계산 순서 · 기물덱 5) → 고행(웨이브 12) → [내 턴: 굴림(재굴림 2) → 확정·정산 → **주사위 3개를 원하는 순서로 전부 이동**(구간마다 그 주사위의 각인 방식으로 밟음/멈춤 처리 → 강제지불·정화·내멈 효과·건설/파괴) → **이번 턴 밟은 기물만 업그레이드**(행동 중에도, 밟은 칸 정가·멈춘 칸 반값) → 턴 종료 = 타락 −1 → **웨이브 방출**] → [웨이브: 몬스터가 한 마리씩 시작칸에서 출발해 죽거나 탈출(시작칸 복귀)할 때까지 한 바퀴를 쭉 이동, 탈출하면 탈출 결과대로 타락] → 보드가 비면 다음 내 턴 → 승리(웨이브 12 보스 전멸) / 패배(강제지불 불능 → 게임 포기, 또는 보스 탈출) → 정비 복귀. 내 턴 동안 **웨이브 프리뷰**(마리별 예상 피해·처치/탈출 판정·멈춤 칸 ★)가 기물을 짓거나 올릴 때마다 갱신된다. 조기 소환·다중 바퀴·원격 업그레이드·강습·안전지대는 없다.

### 기획안 v2.2의 모호점 해석 (구현 확정 사항)

| 항목 | 확정 |
|---|---|
| 웨이브 프리뷰의 기준 보드 | 방출 직전 상태 = 현재 보드에 **턴 종료 시 타락 카운터 −1(만료 처리 포함)** 을 적용한 보드. 그래야 난수 기물이 없을 때 실제와 정확히 일치한다 |
| 탈출 결과(타락)의 적용 시점 | 같은 웨이브의 몬스터가 **전부 끝난 뒤** 한꺼번에. 앞 마리의 무작위 타락 배치가 뒷 마리의 경로·피해를 바꾸지 않아 프리뷰가 정확히 맞는다 |
| 탈출 판정 | 정방향으로 시작칸에 닿는 걸음에서 즉시 탈출(그 걸음은 밟지 않음). 역방향(거울) 통과·종탑 후퇴·통로 이동은 탈출이 아님 |
| 이동 한도 | 거울·종탑만 있는 보드에서 몬스터가 왕복 루프에 빠질 수 있다. 한 바퀴 해석의 패턴 이동 60회를 넘기면 탈출로 처리(로그 `이동 한도 초과 · 탈출 처리`) — 교착 방지 |
| 미끼의 "G칸 이내" | 몬스터가 미끼 칸을 **밟을 때**, 그 이동의 도착 칸이 미끼에서 앞으로 G칸 이내(도착 칸 자체는 제외)면 여기서 멈추고 남은 이동 소멸. 뒤에 있는 미끼가 몬스터를 앞으로 끌어당기지는 않는다. 성문이 먼저 |
| 성문·미끼와 점프 몬스터 | 두 기물은 몬스터가 그 칸을 **밟을 때만** 판정 — 점프(2) 몬스터가 건너뛴 홀수 칸의 성문·미끼는 무력 (§8.5 "홀수 칸 기물 무력" 우선) |
| 성문 닫힘 | 건설 시 닫힘 1(= G1), 업그레이드 시 닫힘 = 새 등급(재장전). 여러 마리 웨이브는 해석 순서대로 소모 |
| 종탑 | 멈춘 그 몬스터만, 진행 방향의 반대로 2G칸(대성당 ×2). 되돌아간 칸은 밟지 않고 후퇴한 자리에서 멈춤 처리 없음. 다음 패턴 이동은 그 자리에서 |
| 거울 | 멈춘 그 몬스터의 **다음 이동 1회**만 역방향. 역방향 이동에서도 밟음/멈춤 판정은 방식대로 |
| 통로 | 내 통로 2개(타락 아님)가 있을 때만. 몬스터: 한쪽에 멈추면 다른 쪽으로(사이 칸 안 밟음), 도착 통로는 멈춤 칸으로 기록되고 추가 효과 없음, 몬스터당 바퀴에 1회. 플레이어: 멈추면 이동/머무름 선택 창, 이동하면 도착 통로가 멈춘 칸(반값 업그레이드) |
| 대성당 오라 | 좌우 2칸 기물의 수치 효과 전부 ×2 — 피해, 늪 감소, 종탑 후퇴, 미끼 범위, 우물 게이지 |
| 업그레이드 창 | 행동 단계(구간 사이)와 이동 완료 후 모두 가능. 밟은 칸 = 등급당 비용÷2, 멈춘 칸 = 비용÷4. 은밀로 지난 칸·순간이동으로 건너뛴 칸·점프의 홀수 칸은 불가. 순간이동 도착 칸은 멈춤(반값) |
| 웨이브 소환 | 내 턴 시작 시 그 턴의 웨이브 몬스터가 시작칸에 대기(보드에 표시). 방출 전에는 이동하지 않는다 |
| 방출 확인 | 프리뷰에 탈출 예상이 있으면 턴 종료 시 확인 창(`그래도 방출` / `돌아가서 보강`). 보스 탈출 예상이면 경고 |
| 로그 속도 | 1× / 4× / 즉시는 표시 속도만. 웨이브 결과는 턴 종료 순간 동기적으로 확정 |
| 공허의 "잠재면" | 윗면이 아닌 면(맞은편·측면·잠재 계층 스킬 모두)의 효과를 2배/제곱 |
| 인내 · 균형 · 헌신 · 축복 · 순례길 등 | v2.1과 동일 (축복은 이 구간에서 밟거나 멈춘 내 기물 등급 +1, 이정표·순례길·회당 등은 기물 11종 재편으로 제외) |
| 귀향 | 내 말이 시작칸에서 시계·반시계 8칸 이내(1~8, 24~31, 0)면 +12 |
| 플레이어 시작 신앙 · 기물덱 | 0 · 소모되지 않는 건설 메뉴 (통로도 한 장으로 여러 개 건설 가능) |
| 정비 초기 상태 | 권장 입문 빌드(6스킬) + 권장 입문 덱(제단·성소·미끼·성문·첨탑). 각인은 비워 둔다 |

## 1. 각인 (18종)

주사위당 1개, 같은 각인 중복 불가. 이동형 5(도약=순간이동 · 비약=점프2 · 순례=서행 · 은신=은밀 · 활보=기본+1) / 굴림형 4(재도 · 인내 · 불굴 · 균형) / 정산형 5(공허 · 종장 · 서장 · 짝의 심장 · 헌신) / 보드형 4(축복 · 정화의 발걸음 · 개척 · 징수). 전체 효과·상세는 `ENGRAVINGS`, `ENGRAVING_DETAILS`와 정비 화면 각인 목록(종류 필터·툴팁).

## 2. 면 스킬 (52종)

v1 57종에서 이동 계층 5종 제외. 귀향 = 시작칸에서 8칸 이내 +12, 각인의 기억 = +5 시작·바퀴당 +3, 집합 참조는 활성 눈 3개 기준. 미열 ×1.25·실선/저음 ×1.3(상한 ×1.3)은 이전 조정값 유지.

## 3. 기물 (11종 — 기준선 3 + 경로 조작 6 + 경제·오라 2)

| 구분 | 기물 (비용) · 동사 |
|---|---|
| 기준선 | 제단 3 · 성소 10 · 첨탑 60 — 때린다 (적밟/적멈 피해) |
| 경로 조작 | 미끼 4 유인한다 · 늪 3 늦춘다 · 성문 12 막는다 · 종탑 12 되돌린다 · 통로 8(×2) 연결한다 · 거울 60 반사한다 |
| 경제·오라 | 우물 3 채운다 · 대성당 400 증폭한다 |

효과는 기획안 §13.1 표 그대로(`PIECES[].desc`, 상세 `PIECE_DETAILS`). 경로 조작은 전부 `resolveLap` 한 곳에서 §13.2 순서(거리 확정 → 성문 → 미끼 → 도착 처리: 통로/거울/종탑 → 탈출 판정)로 처리한다. 업그레이드 등급당 비용÷2(멈춘 칸 ÷4, **밟은 칸만**), 판매 비용×G÷2, 파괴 최종 비용×1.5, 사악한 기물 비용 2G+G×M, 정화 1→+2씩. 모두 올림. 2차 후보(§13.3)는 범위 밖.

## 4. 몬스터·웨이브 — 데이터 정의

`Monster { id, name, icon, moveMode, pattern:[이동 N…], leak:{count, type, placement} }` — 이동만 하며 HP는 웨이브 표가 정한다.

| 이름 | 이동 | 패턴 | 탈출 결과 |
|---|---|---|---|
| 순례자 ○ | 기본 | 5·4·6·5 | 잠식 1 · 빈 칸 무작위 |
| 약탈자 ◇ | 기본 | 7·6·8 | 부식 2 · 기물 있는 칸 우선 |
| 도약자 ◆ | 점프(2) | 6·6·8 | 잠식 2 · 시작칸 앞 8칸 이내 |
| 거체 □ | 서행 | 3·3·4 | 둥지 1 · 최고 등급 기물 칸 |

웨이브 12 `WAVES` = 순례자 / 순례자 / 약탈자 / 순례자 / 약탈자×2 / 거체 / 순례자+약탈자 / 도약자 / 약탈자×3 / 거체+순례자 / 도약자+약탈자 / **보스 대주교(거체, 탈출 = 패배)**. HP = 기획안 §8.6 표 × `HP_RATIO`(= 0.5/0.7, §7 참조). 타락 유형 `CORRUPT_TYPES` = 잠식(3) · 부식(2) · 둥지(4). `new TndGame({ monsters, waves })`에 정의 사전과 웨이브 배열을 넘기면 코드 수정 없이 동작한다 (테스트: 점프 몬스터 + 연속 둥지 + 커스텀 보스).

## 5. 조작 (마우스 전용)

정비: 각인 목록 클릭 → 각인 슬롯 클릭(우클릭 회수) / 스킬 목록 클릭 → 면 클릭(우클릭 회수) / 눈 ± / ◀▶ / 기물 목록(티어 필터) 클릭 → 덱, 덱 슬롯 우클릭 제거 / 고행 시작.
고행: 주사위 클릭 = 잠금(굴림 단계)·구간 이동(행동 단계) / 주사위 호버 = 현재 위치 기준 경유(연한)·도착(진한) 칸 프리뷰 / 경로 계획 토글 = 남은 주사위 순열의 멈춤 후보 점 표시 / 웨이브 프리뷰 블록 호버 = 그 몬스터의 경로·멈춤 칸 강조, 모든 몬스터의 멈춤 칸 ★ 상시(경로 조작으로 옮겨진 ★에는 원인 아이콘 ▮성문 ⚑미끼 ⇄통로) / 이번 턴 밟은 내 기물(↑ 정가 · ½ 반값 표시) 클릭 = 업그레이드 창, 지나가지 않은 기물은 흐리고 클릭 불가 / 턴 종료(웨이브 방출, 탈출 예상이면 주황색 + 확인 창) / 로그 속도 1×·4×·즉시 / 대화창(지불·판매·게임 포기 / 정화 / 파괴 / 건설 / 통로 이동) / 덱 정보.

기획안의 HP 곡선은 몬스터 이동 방식(점프·서행)을 모델링하지 않은 시뮬레이션(§18 "미검증")에서 나온 값이라, 서행 거체가 모든 칸에서 멈춤 피해를 받고 점프 도약자가 홀수 칸을 건너뛰는 본 구현에서는 웨이브별 잠재 피해가 들쭉날쭉해(거체 웨이브 ≫ 도약자 웨이브) §18.1의 방법(중급 피해 중앙값 × 0.7)을 그대로 적용하면 곡선이 매끈하지 않다. 그래서 기획안 표의 **모양은 유지**하고 §18.4 노브 1(HP 비율)만 0.7 → 0.5로 낮췄다. 결과는 기획안이 의도한 "준중급 부분 성공 · 중급 대부분 승리 · 상급 전승"의 경사이고, 하위 빌드의 패인은 강제지불(입문)과 보스 탈출(준중급)로 §9의 서술과 같다. 웨이브별 잠재 피해 실측은 progress.txt 반복 10.
