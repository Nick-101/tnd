# TnD 결합 데모 — 기획서 (plan, 결합 v2.1 개정: 몬스터·웨이브)

> 주사위 덱빌딩 엔진(4계층 면 스킬 · 단일 누산기 · 올림) 위에 모노폴리 디펜스를 결합한 단일 고행 데모. 원본 기획안(TnD 결합 데모 기획안 v2.1)의 규격을 따른다.
> 코드: `js/tnd-config.js`(각인 18 · 면 스킬 52 · 기물 20 · 몬스터 4종 · 웨이브 3 · 타락 3유형) · `js/tnd-game.js`(순수 로직: `calcFaithPoints` / `convert` / `resolveMove` — 플레이어와 몬스터가 같은 함수) · `js/tnd-render.js`. 검수: `test/tnd.test.mjs`, `test/tnd-bot.mjs`. 스테이지 데모(design/plan.md)는 그대로 유지.

## 핵심 루프 (구현 범위)

정비(주사위 3개: 각인 1 + 면 스킬 6 · 눈 무제한 · 계산 순서 · 기물덱 5) → 고행 → [플레이어 턴: 굴림(재굴림 2) → 확정·정산 → **주사위 3개를 원하는 순서로 전부 이동**(구간마다 그 주사위의 각인 방식으로 밟음/멈춤 처리 → 강제지불·정화·내멈 효과·건설/파괴) → 건설 단계(**원격 업그레이드**, 이번 턴 멈춘 칸 반값) → 턴 종료(타락 −1)] → [적 턴: **보드 위 모든 몬스터가 순서대로 패턴의 다음 이동**(이동만), 의도는 마리별로 항상 공개, 시작칸으로 돌아오면(완주) 그 몬스터의 완주 결과대로 타락 생성] → 웨이브(턴 1·7·14 누적 소환, 보드가 비면 조기 소환) → 승리(마지막 웨이브까지 전부 처치) / 패배(강제지불 불능 → 게임 포기) → 정비 복귀. 강습·안전지대·비행은 없다.

### 기획안 v2.1의 모호점 해석 (구현 확정 사항)

| 항목 | 확정 |
|---|---|
| 웨이브 소환 시점 | 플레이어 턴 시작 시 `턴 ≥ 소환 턴`인 웨이브를 모두 소환(턴 1 웨이브는 고행 시작 직후). 소환된 몬스터는 그 턴의 적 턴부터 이동 |
| 조기 소환 | 보드에 몬스터가 0마리이고 다음 웨이브가 남았을 때, 대화창 밖(굴림·행동·건설 단계)이면 즉시. 소환된 웨이브의 원래 소환 턴은 무시, 그 다음 웨이브 일정은 그대로 |
| 완주 판정 | 이동 경로가 시작칸(0)을 지나는 걸음마다 완주 1회(순간이동도 통과로 친다). 시작칸에서는 밟음/멈춤 효과 없음. 완주 타락은 그 즉시 생성(카운터 = 유형 기본값) |
| 타락 배치 규칙 | 시작칸·이미 타락한 칸 제외. 빈 칸 무작위(기물 없는 칸 → 부족하면 아무 칸) / 기물 있는 칸 우선(내 기물 칸 무작위 → 빈 칸) / 최고 등급 기물 칸(동률 무작위 → 빈 칸) / 시작칸 앞 8칸 이내(1~8 → 빈 칸) / 연속 N칸(시작칸을 끼지 않고 전부 타락 가능한 구간 중 무작위) |
| 타락 만료 | 잠식: 내 기물 파괴 후 사악한 기물 G1(있으면 +1) / 부식: 내 기물만 파괴, 빈 칸·사악한 기물이면 잠식과 동일 / 둥지: G2(있으면 +2) |
| 몬스터 이동 | `resolveMove`를 플레이어와 공유(이정표 미적용). 점프(2)는 짝수 번째 걸음과 도착 칸만 밟음, 서행은 모든 경유 칸 밟음+멈춤, 순간이동은 도착 칸만. 마리마다 훅 독립 발동, 처치되면 그 자리에서 이동 종료 |
| 승리 시점 | 마지막 웨이브가 소환된 뒤 보드의 몬스터가 0마리가 되는 순간(처치 로그 직후). 이전 웨이브 전멸은 승리 아님 |
| 공허의 "잠재면" | 윗면이 아닌 면(맞은편·측면·잠재 계층 스킬 모두)의 효과를 2배/제곱 |
| 인내 | 잠근 채 턴 종료 → 다음 턴에도 잠긴 채 유지되며 눈 +1(누적, 최대 6). 굴리면 초기화 |
| 균형 | 턴 시작 굴림에는 적용 안 됨(직전 눈이 없음), 재굴림에만 |
| 헌신 | 활성면에 스킬이 없으면 기본 눈합에 눈×3으로 넣는다 |
| 축복 | 이 구간에서 밟거나 멈춘 내 기물 모두 등급 +1로 취급 (밟음은 멈춤을 포함) |
| 이정표 | 이동당 1회, 밟은 첫 이정표가 그 구간의 거리를 +1 (은밀은 밟지 않으므로 제외). 프리뷰도 같은 함수 |
| 성좌 오라 | 적이 밟는 모든 칸에서 적멈 훅도 발동, 타락 칸이면 카운터 −1 (전 보드) |
| 성배 오라 | 정산 전후 잔량 9 고정 → 모든 신앙치가 1:1 |
| 신전 오라 | 신전 자신을 제외한 내 기물 등급 +2, 턴 시작 신앙 +10×신전 등급 |
| 종탑 후퇴 | 멈춘 그 몬스터만 2G칸 후퇴(시작칸 0까지). 되돌아간 칸은 밟지 않음 |
| 성문 | 멈춘 그 몬스터의 다음 이동 1회 취소(패턴 인덱스는 소비). 의도 패널에 `이동 취소 (성문)` |
| 심판소·성문·종탑 | 멈춘 그 몬스터에게만 적용 (마리별) |
| 심판소 | 그 몬스터 현재 신앙의 5G% (대성당 ×2 포함, 최대 100%) 올림 |
| 순례길 연쇄 | 멈춤 효과 즉시 G칸 기본 이동, 도착 칸에서 다시 전체 상호작용 (이정표·연쇄 중첩 가능) |
| 멈춘 칸에서의 업그레이드 | 멈춤 시에는 창을 띄우지 않고, 건설 단계에서 어느 기물이든 클릭해 업그레이드(멈춘 칸은 등급당 비용÷4) |
| 플레이어 시작 신앙 · 기물덱 | 0 · 소모되지 않는 건설 메뉴 (v1과 동일) |
| 정비 초기 상태 | 권장 입문 빌드(6스킬) + 권장 입문 덱(제단·제단·성소·우물·첨탑). 각인은 비워 둔다 |

## 1. 각인 (18종)

주사위당 1개, 같은 각인 중복 불가. 이동형 5(도약=순간이동 · 비약=점프2 · 순례=서행 · 은신=은밀 · 활보=기본+1) / 굴림형 4(재도 · 인내 · 불굴 · 균형) / 정산형 5(공허 · 종장 · 서장 · 짝의 심장 · 헌신) / 보드형 4(축복 · 정화의 발걸음 · 개척 · 징수). 전체 효과·상세는 `ENGRAVINGS`, `ENGRAVING_DETAILS`와 정비 화면 각인 목록(종류 필터·툴팁).

## 2. 면 스킬 (52종)

v1 57종에서 이동 계층 5종 제외. 귀향 = 내 말이 시작칸에서 시계·반시계 8칸 이내(1~8, 24~31, 0)면 +12, 각인의 기억 = +5 시작·바퀴당 +3, 집합 참조는 활성 눈 3개 기준. 미열 ×1.25·실선/저음 ×1.3(상한 ×1.3)은 이전 조정값 유지.

## 5. 조작 (마우스 전용)

정비: 각인 목록 클릭 → 각인 슬롯 클릭(우클릭 회수) / 스킬 목록 클릭 → 면 클릭(우클릭 회수) / 눈 ± / ◀▶ / 기물 목록(티어 필터) 클릭 → 덱, 덱 슬롯 우클릭 제거 / 고행 시작.
고행: 주사위 클릭 = 잠금(굴림 단계)·구간 이동(행동 단계) / 주사위 호버 = 현재 위치 기준 경유(연한)·도착(진한) 칸 프리뷰 / 경로 계획 토글 = 남은 주사위 순열의 멈춤 후보 점 표시 / 적 의도 패널 호버 = 경로 강조, 도착 칸 ★ 상시 / 건설 단계에 내 기물 클릭 = 업그레이드 창(등급 선택·총액·반값 뱃지) / 상단바 조기 소환(보드가 비었을 때만 활성) / 턴 종료 / 대화창(지불·판매·게임 포기 / 정화 / 파괴 / 건설) / 덱 정보.

## 6. 화면

상단바(턴 · 신앙 · `웨이브 k/3 · 몬스터 n마리` · 다음 웨이브 턴과 구성 + **조기 소환** 버튼 · 기물/타락 수 · 게이지) / 우측 상단 의도 패널(**몬스터 한 마리당 한 행**: 아이콘·HP 바·`▶거리 방식 → ★도착`·완주까지 남은 칸·완주 결과 요약·경유 범위·패턴 진행, 행 호버 시 그 몬스터의 경로만 하이라이트) / 마름모 보드(티어 로마자, IV·V는 크게, 모든 몬스터의 도착 칸 ★ 적색 — 겹치면 `★×2`, 경로 계획 점과 겹치면 이중 테두리, 몬스터 말은 종류별 형태 ○◇□◆ + 머리 위 HP, 타락 칸은 `유형 카운터` 뱃지) / 중앙 주사위 판(순번 ①②③ = 계산 순서, 각인 이름과 이동 방식, 눈, **면 상태 블록**: 스킬이 있는 면마다 `활성/맞은편/측면` 상태 칩 + 스킬 이름 + `✓ 효과`(발동) 또는 흐림(`조건 ✕` / `잠재면만` 등 미발동 사유), 공허 2배 표시, 각인 발동(헌신·짝의 심장) 행, `발동 k/n` 요약 — 정산 프리뷰와 같은 `calcFaithPoints` 결과, `구간 k/3`, 사용한 주사위 흐림) / 어두운 순차 로그(결정=금 · 사건=주황 · 행동=흰 · 계산=회/청/적, 효과 없는 경유는 `밟음 칸 a~b (효과 없음)` 한 줄로 접음).
