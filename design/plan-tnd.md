# TnD 결합 데모 — 기획서 (plan, 결합 v1)

> 주사위 덱빌딩 v2 엔진 위에 모노폴리 스타일 디펜스를 결합한 단일 고행 데모. 원본 기획안(TnD 결합 데모 기획안 v1)의 규격을 따른다.
> 스테이지 데모(design/plan.md)는 그대로 유지하며, 타이틀 화면에서 두 모드를 선택한다.
> 코드: `js/tnd-config.js`(데이터) · `js/tnd-game.js`(순수 로직, `calcFaithPoints`/`convert` 순수 함수) · `js/tnd-render.js`(DOM). 검수: `test/tnd.test.mjs`, `test/tnd-bot.mjs`.

## 핵심 루프 (구현 범위)

정비(샌드박스: 스킬 57종·기물 14종 전부 제공, 같은 스킬 1개 제한, 눈 증감 무제한, 기물덱 5장, 순서 변경) → 고행 시작 → [플레이어 턴: 굴림(재굴림 2) → 확정 → 정산(신앙치→게이지·콤보→신앙) → 이동 주사위 선택 → 칸 상호작용(강제지불/정화/내 기물 효과+업그레이드/건설·파괴) → 턴 종료(타락 −1)] → [적 턴: (굴림→신앙+눈→이동→밟음)×3, 한 바퀴마다 바퀴 수만큼 타락 생성] → 승리(적이 지불 불능) / 패배(강제지불 불능 → 게임 포기) → 정비 복귀(구성 유지, 재도전).

### 기획안 v1의 모호점 해석 (구현 확정 사항)

| 항목 | 기획안 | 확정 |
|---|---|---|
| 스킬 총수 | 본문 "총 53종", 표 합계 57종 (v2 48 − 여유 + 신도·성전·순교·응징·귀향 + 이동 5종) | **표 기준 57종** |
| 플레이어 시작 신앙 | 미지정 | **0** (첫 정산으로 시작. `PLAYER_START_FAITH`) |
| 기물덱의 소모 여부 | 미지정 ("덱에서 하나를 골라 건설") | **소모되지 않는 건설 메뉴** (§10 AI가 같은 기물을 반복 건설하는 것과 일치) |
| 정비 초기 상태 | "모든 스킬·기물 제공" | **권장 입문 빌드 + 입문 덱 프리셋** 장착 상태로 시작 (바로 플레이 가능) |
| 고행 시작 조건 | 기물덱 5장 | **정확히 5장** 필요 (버튼에 안내) |
| 타락+내 기물 칸에 도착 | 순서 미지정 | 강제지불(적 기물) → 정화 → 내 기물 효과·업그레이드 → 건설/파괴 순 |
| 순례길 연쇄 | "추가 G칸 이동 후 밟음 판정" | 업그레이드 창 응답 후 연쇄 이동, 도착 칸은 다시 전체 상호작용 (순례 ×2면 연쇄 2회) |
| 게이지 10칸 가득 찬 상태(우물) | 미지정 | 다음 정산 첫 충전이 즉시 신앙 1 (필요 0) |
| 종탑 후퇴로 시작칸을 거꾸로 지남 | 미지정 | 바퀴 수 변화 없음 |
| 헌금함 | 적 턴 중 플레이어 선택 | 적 턴을 멈추고 헌납량(0~3G) 선택 창 → 응답 후 적 턴 재개 |
| 2.4의 "최종 내림" | 결합판은 올림 | 누산기 **매 단계 올림**, 축적 절반 올림, 업그레이드·판매·파괴 비용 올림 |

## 1. 주사위 스킬 (57종)

덱빌딩 v2 표를 이식(여유 제거)하고 ★ 재정의 3종(신도·각인·반복 상한 15) + ☆ 신규(보드 참조 4종, 이동 계층 5종). 전체 값·상세 설명은 `js/tnd-config.js`(`TND_SKILLS`, `TND_SKILL_DETAILS`)와 정비 화면 스킬 목록(계층 필터, 툴팁)에서 확인. 미열 ×1.25·실선/저음 ×1.3은 스테이지 데모의 조정값을 공유한다(상한 ×1.3 준수). 성장형은 고행 시작 시 초기화된다.

## 2. 기물 (14종)

| 이름 | 비용 | 플레이어가 밟을 시 | 적이 밟을 시 |
|---|---|---|---|
| 우물 | 2 | 게이지 +2G칸 | −G |
| 묘지 | 2 | — | −(1+N), 타락해도 유효 |
| 제단 | 3 | 신앙 +1 | −(2G+N) |
| 봉화 | 3 | 좌우 G칸 타락 카운터 +2 | −G |
| 정화소 | 3 | 정화 비용 1로 초기화 | −G |
| 순례길 | 3 | 추가 G칸 이동 후 밟음 | −G |
| 회당 | 4 | 다음 정산 누산기 +3G | −(G+N) |
| 성물함 | 4 | 다음 턴 재굴림 +1 (G≥4: +2) | −(G+N) |
| 종탑 | 4 | — | −G, 적 말 G칸 후퇴 |
| 헌금함 | 4 | — | 최대 3G 헌납 → 2배 차감 |
| 성소 | 5 | — | −(3G+N) |
| 성문 | 5 | — | −G, 남은 굴림 취소 |
| 세리 | 6 | — | −(G×N) |
| 첨탑 | 8 | — | −(G²+N) |

업그레이드 등급당 비용÷2(올림), 판매 비용×G÷2(올림), 사악한 기물 비용 2G+G×M, 파괴 최종 비용×1.5(올림), 정화 1→+2씩.

## 3. 상수

적 시작 신앙 100 · 적 주사위 1·1·2·2·3·3 × 3회 · 타락 카운터 3 · 타락 생성 누진(`CORRUPT_PER_LAP='laps'`, 원안은 1) · 게이지 10 · 콤보 최대 9 · 보드 32칸(마름모, 시작칸 0 건설 불가).

## 4. 조작 (마우스 전용)

정비: 주사위 카드 클릭=전개도 / ◀▶ 순서 / 면 클릭=선택 / 스킬 클릭=(면 선택 상태면 즉시 장착, 아니면 스킬 선택 → 장착 가능 면 강조) / 스킬 면 우클릭=회수 / 눈 ±(무제한) / 기물 목록 클릭=덱 추가, 덱 슬롯 우클릭=제거 / 고행 시작 / 타이틀로.
고행: 주사위 클릭=잠금(굴림 단계)·이동 선택(행동 단계) / 굴림·확정 / 보드 칸 호버=정보 툴팁, 행동 단계에 도착 가능 5칸 강조 + 주사위 번호 / 상호작용 창(지불·판매·게임 포기 / 정화·건너뛰기 / 등급 선택+총액·업그레이드 / 파괴 / 덱에서 건설·건너뛰기 / 헌납량) / 덱 정보 / 종료 후 정비로 복귀.

## 5. 화면

상단바(턴·신앙·적 신앙·바퀴·기물/타락 수·게이지 10칸) / 중앙 마름모 보드 700px(칸 ID, 기물 이름·등급, 타락 오버레이+카운터, 말 ●■, 도착 가능 칸 금색 강조) / 보드 중앙 주사위 판(순번, 잠금, 예상 신앙치→신앙, 굴림·확정) / 우측 어두운 로그창(결정=금, 사건=주황, 행동=흰, 계산=회색/청/적, 한 줄씩 순차 출력) / 대화창 팝업 / 종료 오버레이.

## 6. 밸런스 검증 (본 구현, 봇 60판 × 3빌드)

| 빌드 | 승률 | 승리 턴 중앙 | 기획안 §10 |
|---|---|---|---|
| 무장착 | 7% | 40 | 18% / 36 |
| 입문 | 97% | 25 | 86% / 28 |

기획안의 시뮬레이션 결과와 같은 구도(무장착 패배 · 입문 아슬아슬 · 중급 빠른 승리)가 재현되어 별도 튜닝 없이 기획안 수치를 그대로 사용했다.

- [x] 정비화면에서 고행을 시작할 수 있다.
- [x] 주사위의 잠금 상태 토글이 잘 작동한다.
- [x] 잠긴 주사위는 굴림에서 제외된다.
- [x] 주사위를 확정하면 주사위 눈과 스킬에 맞게 신앙치를 획득한다.
- [x] 주사위를 하나씩 사용하여 그 만큼 이동한다.
- [x] 적이나 플레이어가 기물을 밟으면 그 효과가 적절하게 발동된다.
- [x] 기물 건설 시, 정화 시, 적 기물 파괴 시, 기물 업그레이드 시 신앙이 정확히 지불된다.
- [x] 타락한 칸을 밟았을 때 정화 상호작용 창이 정상적으로 뜬다.
- [x] 플레이어 기물이 있는 칸을 밟았을 때 업그레이드 창이 정상적으로 뜬다.
- [x] 타락 카운터가 0이 되면 적 기물이 건설된다. 만약 플레이어 기물이 있다면 파괴되고 건설된다.
- [x] 강제지불 시 기물 판매가 가능하다.
- [x] 고행 클리어 이후 정비 화면으로 전환된다.
- [x] 브라우저 콘솔에 에러가 0건이다.

### 추가 완료 기준 (결합판 신규 시스템)

- [x] 신앙치가 게이지·콤보 규칙대로 신앙으로 변환되며, 변환표(§3.3)의 값과 일치한다.
- [x] 콤보가 정산 종료 시 0으로 초기화되고 게이지 잔량만 이월된다.
- [x] 예상 신앙치·예상 신앙 프리뷰가 실제 정산 결과와 일치한다.
- [x] 이동 계층 스킬이 해당 주사위를 이동에 사용할 때만 발동한다.
- [x] 같은 스킬을 두 면에 장착할 수 없다.
- [x] 정비에서 변경한 주사위 순서가 고행의 정산 순서에 반영되고, 고행 중에는 변경할 수 없다.
- [x] 기물 효과의 `+N`이 보드 위 내 기물 수를 정확히 반영한다.
- [x] 다단 업그레이드 시 총액이 정확히 계산되어 지불된다.
- [x] 적이 한 바퀴 돌 때 바퀴 수만큼 타락이 생성된다.
- [x] 타락한 칸의 플레이어 기물은 적이 밟아도 발동하지 않는다 (묘지 제외).
- [x] 이미 사악한 기물이 있는 칸의 타락이 만료되면 등급이 1 상승한다.
- [x] 적이 신앙을 지불하지 못하면 즉시 승리 처리되고, 플레이어가 강제지불을 못 하면 게임 포기 버튼이 노출된다.
- [x] 정비로 복귀했을 때 주사위·기물덱 구성이 유지된다.
- [x] 모든 로그가 §8의 등급·색상 규칙대로 표시되며 한 줄씩 순차 출력된다.
